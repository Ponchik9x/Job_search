# Job_search


		1. Получаем вакансии по API (без выборки ключей, полный словарь)

		2. Сохраняем в файл (JSON например)

		3. Читаем из файла (список словарей) и создаем на его основе список объектов класса Вакансии (выборка полей)

		4. Работаем со списком объектов класса Вакансии: фильтрация, сортировка

		5. При записи в файл преобразовываем из списка объектов класса Вакансии обратно в список словарей?

		6. Удаление - это просто очистка файла или какую-то вакансию удалить надо? По какому критерию это делать?

		7. Добавление вакансии - через конструктор класса Вакансии создать объект и добавить его к списку объектов Вакансии, 
            а потом при записи в файл преобразовать обратно в список словарей.
